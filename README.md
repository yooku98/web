# Website Design Services — William Thompson

Single-page sales site for my freelance website design service: what I build, how pricing works, and how to get in touch.

**Live demo:** https://yooku98.github.io/web/

## What's on the page

- Hero and value proposition (custom, responsive, data-informed design)
- Transparent pricing packages
- Enquiry via WhatsApp (pre-filled message) or email

## Stack

A single `index.html` with inline CSS/JS (Google Fonts: Playfair Display, Manrope). No build step.

## Run locally

```bash
python3 -m http.server 8000
```

## Deployment

Served by GitHub Pages from the root of `main`.
